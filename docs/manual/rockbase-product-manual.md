## 1. 产品简介

Rockbase 是一台**比特币验证节点 + 独立挖矿**一体机。

插上电源、连上网络后，它会自动开始工作：

- 验证比特币网络上的区块；
- 为你局域网里的矿机提供挖矿服务；
- 通过自带的**触摸屏幕**和**网页**实时显示运行状态。

你不需要安装任何软件，也不需要懂技术，按本说明书操作即可。

### 本产品能做什么

- 验证比特币网络上的区块，保证你挖到的币是真实有效的；
- 为你局域网里的矿机提供挖矿服务，矿机直接连它即可挖矿；
- 通过触摸屏幕和网页，随时查看节点、挖矿、矿机的运行状态；
- 支持 WiFi 和有线两种方式联网；
- 支持在线升级固件，保持设备最新。

### 本产品不能做什么

- **不保证挖到币**：独立挖矿能否出块取决于算力和运气，算力越小概率越低，请勿把它当作稳定收益来源；
- **不保存全部历史数据**：设备只保留验证所需的数据，不保存比特币的全部历史记录，因此不能用于需要完整链数据的场景；
- **只支持比特币**：不能用于其他加密货币；
- **不是矿池**：它只为你自己的矿机提供服务，不对外提供公共矿池；
- **不是路由器**：它不能给其他设备提供网络，请把它和矿机都接到你自己的路由器下。

## 4. 快速上手

按下面 3 步，让设备开始工作：

**第 1 步：连接电源**

将电源适配器插入设备电源口，另一端接插座。

**第 2 步：等待开机**

设备开机后，触摸屏幕会自动点亮并显示状态。
开机大约需要 〔待补充：时间〕。

![开机后 LCD 首屏](images/lcd-boot.png)

**第 3 步：连接网络**

设备需要联网才能正常工作。连接方法见 [第 5 章](#5-连接网络)。

> 联网成功后，设备会自动开始同步，无需其他操作。
> 同步进度可在屏幕或网页上查看（见第 6、7 章）。

## 5. 连接网络

设备支持 **WiFi** 和 **有线** 两种方式联网，任选其一。

### 5.1 方式一：连接 WiFi

1. 用电脑或手机打开浏览器，访问设备地址：`〔待补充：默认地址，如 http://192.168.x.x〕`。
2. 在网页中找到 **WiFi** 页面。
3. 选择你的 WiFi 名称，输入密码，点击保存。
4. 设备连接成功后，页面会显示已连接。

![网页 WiFi 配置页](images/web-wifi.png)

### 5.2 方式二：有线连接

1. 用网线将设备 USB 口与路由器连接。
2. 设备会自动获取网络，无需设置。

![有线连接示意](images/wired-connection.png)

> **注意：请使用设备支持的 USB 有线网卡。**
> 设备只识别特定芯片的 USB 有线网卡，其他芯片的网卡插上后无法使用。
> 〔待补充：面向消费者的"推荐网卡型号"清单。
> 当前仅支持以下芯片的 USB 有线网卡：
> - Realtek RTL8152（百兆）
> - Realtek RTL8153（千兆）
> 选购时请确认网卡芯片为上述型号。〕

### 5.3 如何确认已联网

- 屏幕 **Network** 页显示已连接；
- 或网页 Dashboard 显示网络正常。

## 8. 接入矿机挖矿

你可以把局域网里的矿机接入 Rockbase，由它提供挖矿服务。

**接入步骤**：

1. 确保矿机与 Rockbase 在同一局域网。
2. 在矿机上设置挖矿地址，指向 Rockbase：
   - 地址：`〔待补充：Stratum 地址，如 stratum+tcp://192.168.x.x:端口〕`
   - 用户名 / 密码：`〔待补充〕`
3. 保存后，矿机开始向 Rockbase 提交工作量。

**确认矿机已接入**：

- 屏幕 **Stratum** 页显示矿机信息；
- 或网页 **Miners** 页看到矿机与算力。

![网页 Miners 页（已接入矿机）](images/web-miners-connected.png)

## 9. 升级固件

当有新版本时，设备支持在线升级。

**升级步骤**：

1. 〔待补充：如何检查新版本，如网页提示 / 手动触发〕
2. 〔待补充：点击升级〕
3. 设备自动下载并安装，期间会自动重启，请勿断电。
4. 重启完成后，可查看版本号确认升级成功。

![网页升级入口 / 升级中](images/web-ota.png)

**注意事项**：

- 升级过程中**不要断电**；
- 升级失败时设备会自动恢复到原来的版本，不会变砖。

## 10. 常见问题

| 问题 | 解决办法 |
|------|----------|
| 屏幕不亮 | 检查电源是否插好、适配器是否正常 |
| 连不上 WiFi | 确认 WiFi 名称和密码正确，信号是否良好 |
| 网页打不开 | 确认电脑/手机与设备在同一网络，地址是否正确 |
| 同步很慢 | 属正常现象，首次同步需要时间，耐心等待 |
| 矿机没反应 | 检查矿机地址、用户名密码是否正确，是否在同一网络 |
| 设备无响应 | 断电 10 秒后重新上电 |

> 〔待补充：更多问题、联系支持方式〕
